# ゲーム別ガイド

全6種類とも自分とCPUの1対1、各1,000の仮想チップで遊びます。ゲーム選択→専用チュートリアル／ゲーム開始→対戦の順です。種類を切り替えても各対戦はアプリ終了まで保持します。

| 種類 | 配札と勝敗 |
|---|---|
| テキサスホールデム | 手札2枚＋共有5枚の7枚から最強の5枚。共有カードは3→1→1枚 |
| オマハ・ハイ | 手札4枚から必ず2枚、共有5枚から必ず3枚。ハイのみ。ハイロー分割なし |
| ファイブカードドロー | 手札5枚。交換前ベット→0〜5枚を1回交換→交換後ベット→5枚で勝負 |
| セブンカードスタッド | 裏2＋表1で開始。表を3枚、最後に裏1枚を追加。7枚から最強の5枚 |
| ラズ | スタッドと同じ配札。Aは1、ストレート・フラッシュを無視。ペアのない低い5枚が強く、最良は5-4-3-2-A |
| ショートデック | 6〜Aの36枚。手札2＋共有5枚。フラッシュ＞フルハウス、A-6-7-8-9もストレート。他は通常の役順位 |

ドローでは交換したいカードをクリック（キーボードならEnter／Space）し、交換ボタンを押します。選び直せます。0枚なら「交換せず進む」です。CPUも1回交換します。

スタッドとラズの緑枠は相手にも見えるカードです。CPUの裏カードは最後の勝負まで非公開です。スタッドは最初の低い表カード、ラズは高い表カードがブリングイン5を支払います。同ランクではクラブ＜ダイヤ＜ハート＜スペードを使用。その後はスタッドが強い公開手、ラズが低い公開手から行動し、公開手が同じなら仮想ディーラーの次の席からです。スートは最終勝敗のタイブレークには使いません。

ホールデム・オマハ・ドローはブラインド5/10。スタッド・ラズは全員アンティ5＋ブリングイン5、ショートデックは全員アンティ5＋ボタンのブラインド5です。

## このアプリのベット設定

全種類で練習用の固定リミットを採用しています。最初のベットラウンド10、後半20ずつ増額。スタッド・ラズは3枚目／4枚目が10、5枚目以降20です。各人各ラウンド合計40まで。通常のポットリミット・オマハやノーリミット卓の賭け方とは異なります。スタッドの4枚目公開ペア時の任意ダブルベットは採用していません。

短いスタックでは双方が支払える額を上限とし、サイドポットは作りません。オールイン後は配札を自動で進めますが、ドローの交換選択はプレイヤーが行います。

## 勝率の意味

Goで5,000回のモンテカルロ計算を行います。見えている自分の手札・共有カード・CPU公開カードと、自分の交換済みカードだけを使い、CPUの実際の裏カードは参照しません。スタッド／ラズでは今後の自分の配札もランダムに仮定します。エクイティは勝率＋引き分け率の半分です。

**ドローの表示は、現在の5枚をそのまま維持した場合のショーダウン勝率です。交換前から交換後の勝率を予言する値ではありません。相手の交換方針や交換枚数から手札範囲は推定しません。**

CPUは役と手札の特徴を使った簡易戦略です。学習モデルやGTOではありません。Kaggleや通信は不要です。ゲーム履歴は終了すると失われ、ウィンドウ設定・音量・チュートリアル完了のみ保存します。
