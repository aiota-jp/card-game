# ルールと練習用の調整

## 共通

Aは1点、2～9は数字どおり、10・J・Q・Kは0点です。合計の1の位を点数とし、9に近い方が勝ちます。最初の2枚で8または9ならナチュラルです。

初期持ち点は1,000、目標は2,000チップ。賭け額は20・50・100・200から選びます。相手の資金によって実際の対応額は減額されます。精算内部では100分の1チップ単位を使い、手数料を含めて管理します。

残り16枚以下になると次の配札前にシャッフルします。バーンカードは省略しています。カードは重複のないシューから配ります。

## プント・バンコ

8デッキを使用します。プレイヤー勝ちは利益1倍、バンカー勝ちは5%の手数料を差し引いた利益0.95倍、タイ勝ちは利益8倍です。タイの場合、プレイヤーとバンカーへの賭けは返却します。

ナチュラルなら即精算。それ以外でプレイヤーは0～5で引き、6・7で止まります。プレイヤーが止まった場合、バンカーは0～5で引きます。プレイヤーが引いた場合のバンカーの追加条件は以下です。

| バンカーの点 | 追加する条件（プレイヤーの3枚目） |
| --- | --- |
| 0～2 | 常に追加 |
| 3 | 8以外 |
| 4 | 2～7 |
| 5 | 4～7 |
| 6 | 6・7 |
| 7 | 止まる |

最初の2枚を表示した後、自動で追加・精算します。「結果を見る」でも進められます。表示する確率は、公開カードと残りカードの枚数を使う3,000回のモンテカルロ計算です。未配札の並びは参照しません。推定値であり、収益の保証ではありません。

## シュマン・ド・フェール

6デッキを使用します。あなた・MISAKI・AYAKA・RINAの4席にそれぞれ1,000チップを用意します。選んだ女性が最初のバンカーです。バンカー以外は共通のプレイヤー手札に賭け、あなたが非バンカーのときはその手札を操作します。

あなたの賭けを優先し、CPUの賭けを加えます。合計はバンカーが対応できる持ち点以内です。バンカーの対応分も配札時に確保します。勝ったバンカーの利益から5%を徴収します。タイは返却です。

プレイヤーは0～4で引き、6・7で止まり、5では選択します。CPUの5は引く／止まるをランダムに選びます。バンカーは基本の追加表に従いますが、3対プレイヤー3枚目9、5対3枚目4はあなたのバンカー時に選択できます。CPUは基本表に従います。

バンカーが負けたら次の資金のある席へ交代し、勝ち・タイでは続投します。あなたのバンカー時には配札前に辞退できます。最初の2枚は自分の操作する手札だけが見え、3枚目は公開され、精算時にすべて開きます。

正式な卓にあるオークション、バンコ宣言、観客からの賭け、細かな席順の優先権は省略しています。

## バカラ・バンク

3デッキを使用します。バンカーはセッション中固定です。プレイヤー役ではあなたが右側、CPUが左側、選んだ女性がバンカーです。バンカー役ではあなたがバンカーになり、CPUが左右を担当します。役は最初の配札前に選びます。

左右それぞれの賭けとバンカーの対応分を確保し、左右を別々に比較して精算します。最小の参加資金は各プレイヤー20、バンカー40チップです。バンカーの左右合算の純利益がプラスのラウンドだけ、その利益から2%を徴収します。片側の勝ちと片側の負けが相殺された部分には手数料を掛けません。これは本アプリで固定した手数料方式です。

初期2枚で3組のいずれかに8・9があれば、全組が追加せず精算します。それ以外では左右のプレイヤーは0～4で引き、6・7で止まり、5で選択します。左右の判断後、バンカーは0～7のどの点でも引く／止まるを選べます。CPUバンカーは5以下で引き、6以上で止まります。

公開されるのは自分の手札と他の組の3枚目です。他の組の最初の2枚は精算まで伏せます。CPUは非公開カードを使って追加判断しません。資金不足または目標達成でセッションを終え、リセットで再開します。

実際のバンクにある銀行権の競り、別の参加者による代理プレイ、複雑な賭けの優先権は省略しています。シュマンとバンクには非公開情報と判断があるため、プントと同じ確率表示を流用していません。履歴はあなたの収支を示し、次の結果を予測するものではありません。
