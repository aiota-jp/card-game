# ゲーム制作の参照指示

ゲームの作成・修正に着手する前に、次の仕様書を開いて読んでください。
C:/work/game-development/ゲーム制作共通仕様書.md

- 共通の好みを参照し、このゲームに該当する固有仕様があれば併せて読む。
- 最新のユーザー指示を優先する。他ゲーム固有の数値・ルールを無断で適用しない。
- 文書の参照だけを理由に、依頼されていない実装やEXE更新を開始しない。
- 決定が変わった場合は該当仕様を更新し、古い内容を同列に残さない。
- 参照先が読めない場合は、読んだことにせずユーザーに伝える。

このプロジェクトは仕様書の「5. CARD GAME LOUNGE（ポーカー等）固有仕様」が対象です。
修正の納品先：C:/work/CardGame/card-game-lounge.exe
他方のゲームのソース・EXEは、このプロジェクトの変更に伴って修正しないでください。
