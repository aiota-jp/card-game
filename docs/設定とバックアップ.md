# 設定・バックアップ・ゲーム終了
更新日：2026-10-18

3ゲーム共通の音声・BGM・効果音のON/OFF、各音量、セリフ速度をホームから設定。設定は既存のcardlounge.*保存キーを共用します。バックアップ対象は音・人物設定とポーカーのチュートリアル達成履歴。持ち点・対局途中・ウィンドウ位置は対象外。配札・精算中は従来どおりホーム移動を制限し、設定・終了ボタンはホームに表示します。

JSONはWindowsの保存／開くダイアログで選択します。復元前に確認し、不正形式・設定値を拒否します。復元前の設定はcardlounge.backup.before-restoreに保持します。ホームの「ゲーム終了」では確認後、Wailsの正常終了とウィンドウ設定保存を行います。持ち点・進行は従来どおり終了時に初期化します。

検証：設定・バックアップ往復、不正データ拒否、復元前データ保持、終了キャンセルを確認。Godotの3作品はtests/settings_backup_test.gd。CardGameはsystem_app_test.goとscripts/settings-tools-check.cjs。

追加検証：go test ./... と go vet ./... 成功。Chrome上で設定保存・バックアップ往復・復元キャンセル・不正形式拒否・終了ボタンの連携、1024/880/390pxの画面を確認。Windows EXEはWebView2環境の初期化成功を確認しました。実機UIの自動操作はWebView2のデバッグ接続が利用できず未確認です。
