# CARD GAME LOUNGE

ポーカー6種類・ブラックジャック・バカラ3種類を1つのWindowsアプリで遊べる、仮想チップの1人用練習アプリです。

## 起動

このフォルダーの **card-game-lounge.exe** を起動してください。Microsoft Edge WebView2 Runtimeが必要です。Go・Node.js・Dockerは不要。画面・画像・音声を同梱し、通常プレイにネット接続は不要です。

## 人物と音声（2026-10-28更新）

MISAKI・AYAKA・RINAにSHIZUE・KATHYを加えた5名を選択できます。既存3名の画像は維持し、追加2名は旧リバーシの実写風素材を使用。人物選択、自己紹介、全ゲームのセリフ、夏服のお祝いに対応しています。

声はC:/work/game-test/reversi-queensの人物別AivisSpeech設定に統一。MISAKI＝凛音エル、AYAKA＝まお、RINA＝みちのくあいり、SHIZUE＝まい、KATHY＝コハク。MISAKIの音程1.10倍補正も反映しています。カード用の原稿を収録し、リバーシのセリフは流用していません。

人物別の話速は録音に反映し、標準再生速度は1倍です。旧標準1.794倍だけを移行し、利用者が変更した速度は保持します。トップの挨拶も同じ再生倍率です。音量初期値30%、音声ON/OFF・停止・再聴・抑揚切替、BGM・効果音の個別設定を利用できます。

## ゲームと進行

- ポーカー：テキサスホールデム、オマハ、ファイブカードドロー、セブンカードスタッド、ラズ、ショートデック。
- ブラックジャック：ヒット・スタンド・ダブルなどで21を目指すディーラー対戦。
- バカラ：プント・バンコ、シュマン・ド・フェール、バカラ・バンク。バンクではプレイヤー／バンカーを選択可能。

5人の実写風TOP（Kathyは対戦中と同じ緑の衣装）を5秒またはボタンで進むとゲーム一覧を表示し、MISAKIが自動で挨拶します。TOP・一覧では専用のラウンジBGMが流れ、挨拶中は減音、ゲームへ移ると各ゲームの音楽へ切り替わります。BGMのON/OFF・音量はTOPと設定から変更できます。人物を選び直すと直前と異なるお誘いを選びます。ゲームへ移動すると挨拶は停止します。

「ホーム」で一覧へ戻れます。配札・精算中は完了を待ちます。アプリ実行中はゲームの持ち点・進行を保持し、終了時に初期化。バカラは従来の4人卓を維持し、SHIZUE／KATHY選択時はCPUの1席を選択人物に置き換えます。バカラは種類と人物ごとに進行を保持します。

ポーカーで相手が0点、ブラックジャック／バカラで自分が2,000点に達すると、選択人物の夏服とお祝いセリフを表示します。水着演出はありません。

音・人物設定とポーカーのチュートリアル達成履歴はJSONでバックアップ・確認付き復元ができます。持ち点・対局途中・ウィンドウ位置はバックアップ対象外です。

## ウィンドウ

自動最大化せず、モニターに合わせた通常サイズを従来より約10%縮小して中央に表示。カードは通常画面で従来より約12%、幅540px以下で約6%拡大。小さい画面では縦スクロールできます。スクロールバーは非表示です。
